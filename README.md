# Versely

An interactive poetry writing web application and creative studio canvas.

## Features
- **Dynamic Writing Canvas**: Add, arrange, edit, and group verse containers across a visual workspace.
- **Poetic Form Scaffolding**: Built-in structures for Free Verse, Haiku, Sonnet, Limerick, and Couplet patterns.
- **Ambient Audio**: Procedural background sound generation using Web Audio API (Rain, Vinyl, Fireplace, Forest).
- **Customizable Themes & Backgrounds**: Texture grids, curated photographic backgrounds, or user-uploaded artwork with contrast tint and blur adjustments.
- **Live Metrics**: Real-time tracking of lines, word count, and syllable metrics.
- **Image & Text Export**: Generate canvas image cards (PNG) formatted 1:1, or export plain text (.txt).
- **Offline Capable**: Standalone client-side application with local draft persistence.

## Getting Started
Open `index.html` in any modern web browser. No installation or build steps required.

## Technologies
- HTML5
- CSS3
- JavaScript (ES6+, Web Audio API, Canvas 2D)
